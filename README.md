# Keyway

[English](./README.md) | [简体中文](./README.zh-CN.md)

Keyway is a cross-platform quick launcher for keyboard-first productivity workflows, inspired by tools such as Raycast, uTools, and ZLaunch.

## Availability

Keyway is in early development and is not ready for everyday use yet. Public builds and installation instructions will be provided when the launcher reaches a usable preview stage.

## Planned Experience

- Open the launcher from anywhere with a global keyboard shortcut.
- Search apps, commands, files, notes, clipboard history, and other local information from one focused interface.
- Run commands and actions without leaving the keyboard.
- Use first-party tools for common daily tasks such as calculations, screenshots, notes, settings, and developer utilities.
- Extend Keyway with sandboxed extensions while keeping the main app and user environment protected.
- Use a consistent desktop experience across Windows, macOS, and Linux.
