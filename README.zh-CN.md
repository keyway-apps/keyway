# Keyway

[English](./README.md) | [简体中文](./README.zh-CN.md)

Keyway 是一个跨平台快速启动器，面向键盘优先的效率工作流，灵感来自 Raycast、uTools 和 ZLaunch 等工具。

## 可用状态

Keyway 仍处于早期开发阶段，暂时不适合作为日常工具使用。当启动器达到可用预览阶段后，会提供公开构建和安装说明。

## 计划体验

- 通过全局键盘快捷键在任何位置打开启动器。
- 在一个聚焦界面中搜索应用、命令、文件、笔记、剪贴板历史和其他本地信息。
- 不离开键盘即可运行命令和动作。
- 使用一方工具处理计算、截图、笔记、设置和开发者工具等日常任务。
- 通过沙箱化扩展扩展 Keyway，同时保护主应用和用户环境。
- 在 Windows、macOS 和 Linux 上获得一致的桌面体验。
